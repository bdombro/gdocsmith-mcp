### Implementation recipe
1. **Inventory constant.** Add an expected-inventory constant to the driver.
   - The ten case IDs from the assessment command, plus the V009 `known-upload-error` variant.
   - The named controls per side and case, taken from the existing branches and `safetyControls`.
   - If the selected IDs aren't exactly the expected set, fail with an incomplete-case error. A bounded subset mode isn't needed.
2. **Fresh destinations.** Before any writes:
   - Reject an `--owned-run-root` that already exists, and reject an existing results or raw-diff path, symlink or not.
   - Keep the existing project-relative, `tasks/parity-evidence/`, no-symlink-ancestor and `0700` checks.
3. **Cleanup accounting.** Make cleanup failures recordable:
   - In `execute`, catch cleanup and marker failures, record them as `{cleanup: "failed", detail}` on the run, and keep the exact child `exitStatus`/`signal`.
   - Count remaining `run-*` directories.
   - Never delete outside the owned directory, and never retry cleanup.
4. **Pure final check.** Export `qualify(report, expected)`. It returns `{pass, reasons[]}` and fails on any of:
   - Missing case or variant identity, or a missing node or cpp observation.
   - A missing named control, or an empty control set.
   - Any control with `baselineWasPassing !== true`, or `requiredAssertion` not in `rejectedBy`.
   - A backend control with `reached !== true`.
   - `ownedRunDirectoriesRemaining > 0`, or any recorded cleanup failure.
   - Inputs not frozen or not current.
   - Any original or target assertion failure, or any launch failure.
   - Any differing case.

   Put `reasons` in the report. Set `process.exitCode` from `pass`. Leave uncaught infrastructure errors uncaught so they stay nonzero.
5. **Identity.** Add `justfile` to the target fingerprint's extra list. Leave the before/after equality and the receipts as they are.
6. **Tests.** Create `tests/parity/run-engine-differential.test.mjs`.
   - Use `node:test` and import only `qualify` plus the inventory. Importing must not trigger a run.
   - Build one complete valid synthetic report.
   - Add one failing case each for: missing case, missing variant, empty control set, missing named control, `reached=false` backend control, `baselineWasPassing=false`, required assertion not rejected, remaining run directory, cleanup failure, malformed or incomplete report, `frozenInputs=false`, `compiledInputsCurrent=false`, raw difference, and launch failure.
   - The valid report passes.
   - Destination rejection can't be tested in-process. Either export a pure `assertFreshDestination` and test it, or the refiner accepts covering it by review only (open question).
7. **Recipe.** Add `parity run_id node="node":` to `justfile`. Place it alphabetically among the plain recipes if feasible, otherwise next to `test-mcp`, and note the reason. It calls `{{node}} tests/parity/run-engine-differential.mjs` with:
   - `--original-root ../gdocsmith-node`
   - `--target-adapter build/cmake/ParityChecks/gdocsmith_parity_adapter`
   - `--vectors` pointing at the existing vectors file
   - `--case-ids` with the ten IDs
   - `--owned-run-root` and `--results` under `…/tasks/parity-evidence/{{run_id}}/`

   The recipe has no dependency on `build`, `configure` or `deps`.
8. **Docs.** Add one AGENTS.md Commands row for `just parity <run_id>`. Add a README note that the run is offline, needs a pre-built adapter, and that a raw difference makes it fail; no claim of a fresh run.

- **Behavior contract:** exit 0 only when `qualify.pass` is true. Raw differences stay red even if every assertion passes. The report and raw-diff files are kept even on failure.
- **Failure and lifecycle:** no overwriting, no cleaning old receipts, and a later step never masks an earlier failure.
- **Local decision boundary:** helper names, how reasons are worded, test fixture shape, and where exactly the recipe goes.
- **Escalate to coord-v2 or the lead:** changes to adapters, vectors or safety assertions; a new case or control; adding a timeout; adding the bijection check to the exit logic; any need to build or run the adapter.
