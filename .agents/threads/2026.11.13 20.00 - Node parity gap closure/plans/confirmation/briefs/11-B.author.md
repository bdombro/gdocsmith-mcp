### Observed current and target state
- Current:
  1. **Missing opening `::section{id=s1}`**: `src/lens/document.hpp:545-549` only emits `::section{...}` when `tab.openingSettings` is set; pageless or default-only tabs omit it. Node (`../gdocsmith-node/src/core/lens/document.ts:499-504`) always emits `openingLine` (`::section{id=...}`).
     - Existing C++ test: `tests/engine/test_import_structure.hpp` explicitly notes `// E1 observed RED: the PAGELESS export emits no ::section{id=s1} line to edit.` and `tests/engine/test_import.hpp` asserts `CHECK(file.tabs[0].markdown.starts_with("::section{id=s1}"));`.
  2. **Extra default tab attributes**: `src/engine/export.hpp:291-298` emits `headerMargin`, `footerMargin`, and `background` unconditionally when present in `documentStyle`, without filtering defaults. Node (`../gdocsmith-node/src/core/lens/document.ts:153-167`, `TAB_SETTINGS_DEFAULT`) omits `background: "#FFFFFF"`, `footerMargin: 36`, `headerMargin: 36`, and `pageNumberStart: 1`.
     - Existing C++ tests: `tests/engine/test_import.hpp` tests non-default values (`headerMargin=24`, `footerMargin=20`, `background=#FFF4CC`, `pageNumberStart=5`); `tests/lens/test_document.hpp` tests invalid values (`nan`, `inf`, `1.5`).
  3. **`styleBaseline` in frontmatter**: `src/engine/export.hpp:218` (`exportStyleSnapshot`) and `src/lens/document.hpp:525` emit `styleBaseline` in YAML frontmatter, and `src/engine/import.hpp:714-721` (`readonlyValidate`) rejects imports if `styleBaseline` differs from the exported snapshot. Node has no `styleBaseline` in `export.ts` or `import.ts`.
     - Existing C++ tests: `tests/engine/test_import.hpp` asserts both `CHECK_FALSE(file.frontmatter.styleBaseline)` (new/non-legacy) and `REQUIRE(file.frontmatter.styleBaseline)` + mutation refusal for legacy/snapshot cases.
  4. **Colon escaping**: `src/lens/render.hpp:17` (`markdownTextEscape`) escapes every `:` (`\\:`), turning `Launch date:` into `Launch date\:`. Node (`../gdocsmith-node/src/core/lens/render.ts:459`) only escapes `:` when it precedes `:(?:pagebreak|section|toc)(?![A-Za-z0-9])` (i.e. `(?<![A-Za-z0-9\\]):(?=:(?:pagebreak|section|toc)(?![A-Za-z0-9]))`).
     - Existing C++ tests: no test in `tests/lens/test_render.hpp` asserts `\\:` escaping.
  5. **Empty plain paragraph (`:style[]{}`)**: `src/lens/render.hpp:126` emits `:style[]{}` whenever `renderSpans(b.spans)` is empty. Node (`../gdocsmith-node/src/core/lens/project.ts`) uses `blockInvisibleIs(block)` to skip invisible empty blocks rather than emitting `:style[]{}`.
     - Existing C++ tests: `tests/lens/test_render.hpp` asserts `CHECK(rendered == "first\n\n:style[]{}\n\n:style[]{}\n");` and `tests/lens/test_document.hpp` asserts `CHECK(parsed.tabs[0].markdown == "\n\nfirst\n\n:style[]{}\n\n");`.
