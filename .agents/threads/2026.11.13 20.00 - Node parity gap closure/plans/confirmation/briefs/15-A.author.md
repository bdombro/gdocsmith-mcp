## Brief

### Why This Task Exists
Close four remaining C++ engine parity gaps against `../gdocsmith-node` identified during Cycle-2 differential and structural testing:
1. **W1 `doc: null` `::section{id=s1}` refusal** (`src/lens/document.hpp:433,442-451`)
2. **W4 `baseValidate` newline mismatch on commented docs** (`src/engine/import.hpp:1070-1077`, `src/lens/document.hpp:571-573`)
3. **Two `11-A` `doctest::may_fail()` cases** (`tests/engine/test_import_structure.hpp:166,192`)
4. **`10-T3` `hiddenChipTabs` `textExport` check** (`src/engine/import.hpp:1204`)

### Current State vs. Target State
- **W1 `doc: null`:** `src/lens/document.hpp:433` assigns `tab.id = "t.0"` when `tabs.empty()`, and `442-451` enforces `An existing tab starts with its opening ::section{id=s1} line.` whenever `sourceEnvelope && !tab.id.empty() && !tab.isDelete`, without checking whether `file.frontmatter.doc` is empty (`doc: null`). Node (`../gdocsmith-node/src/core/lens/document.ts:1104,1127-1135`) only requires `::section{id=…}` when `existing` is true (`file.doc !== null && Boolean(tab.id)`).
- **W4 `baseValidate`:** `src/engine/import.hpp:1070-1077` re-exports `live` with empty comments `{}` and compares `base.tabs[i].markdown != current.tabs[i].markdown`. Because `src/lens/document.hpp:571-573` emits an extra `\n` before `::comment{...}` when `!file.comments.empty()`, `base.tabs[i].markdown` has a trailing `\n` that `current.tabs[i].markdown` lacks, causing a false `staleBase` error on any commented document.
- **`11-A` `may_fail()` #1 (`tests/engine/test_import_structure.hpp:166`):** `src/engine/export.hpp:361-365` emits `namedStyleSet=ns1` on the tab line whenever `tab.namedStyles["styles"]` is non-empty, whereas Node (`../gdocsmith-node/src/core/engine/export.ts`) does not emit `namedStyleSet` on tab lines, causing `beforeLines[0].ends_with("title=Overview pageful}")` to fail.
- **`11-A` `may_fail()` #2 (`tests/engine/test_import_structure.hpp:192`):** `src/engine/import.hpp:766-768` throws `"The requested header/footer section does not exist."`, whereas Node (`../gdocsmith-node/src/core/engine/import.ts:1047`) throws `` `tab "${section.title}" has ${breaks + 1} section${breaks ? "s" : ""}, so there's no section ${segment.section}` ``.
- **`10-T3` `hiddenChipTabs` (`src/engine/import.hpp:1204`):** `refresh()` only calls `drive.textExport(id)` when a comment has a non-empty `quote()`. Node (`../gdocsmith-node/src/core/engine/export.ts:245-250`) calls `drive.textExport(model.docId)` when `hiddenChipTabs(model).length > 0` **or** a non-deleted comment has `quotedFileContent?.value`.

### Non-Goals
- Do not modify `../gdocsmith-node`.
- Do not change `batchUpdate` ordering or `export.orig.md` file-preservation semantics.
- Do not address `D-K5` (`V010-cross-doc-image-copy` read order) in this task.

### Implementation Recipe
1. **W1 `doc: null` `::section{id=s1}` (`src/lens/document.hpp:444`):**
   - Update the guard from `if (sourceEnvelope && !tab.id.empty() && !tab.isDelete)` to `if (sourceEnvelope && !file.frontmatter.doc.empty() && !tab.id.empty() && !tab.isDelete)`.
   - Add a unit test in `tests/lens/test_document.hpp` (and/or `tests/engine/test_import.hpp`) verifying `doc: null` with `gdocsmith: "1.0"` and no `::section{id=s1}` parses without error.
2. **W4 `baseValidate` newline mismatch (`src/engine/import.hpp:1073-1077`):**
   - Normalize trailing `\n` on `base.tabs[i].markdown` and `current.tabs[i].markdown` before comparing in `baseValidate` (e.g. a local `trimTrailingNewlines` helper).
   - Add a unit test in `tests/engine/test_import.hpp` verifying `baseValidate` succeeds on a commented document.
3. **`11-A` `may_fail()` #1 (`src/engine/export.hpp:361-383`, `tests/engine/test_import_structure.hpp:166`):**
   - Remove `namedStyleSet` emission from `src/engine/export.hpp:361-383` (verify no existing `test_export.hpp` / `test_document.hpp` assertions depend on `namedStyleSet=ns1`).
   - Remove `* doctest::may_fail()` from `tests/engine/test_import_structure.hpp:166`.
4. **`11-A` `may_fail()` #2 (`src/engine/import.hpp:766-768`, `tests/engine/test_import_structure.hpp:192`):**
   - Update `src/engine/import.hpp:766-768` to throw:
     `"tab \"" + section.title + "\" has " + std::to_string(breaks + 1) + " section" + (breaks ? "s" : "") + ", so there's no section " + std::to_string(*segment.section)`
   - Remove `* doctest::may_fail()` from `tests/engine/test_import_structure.hpp:192`.
5. **`10-T3` `hiddenChipTabs` (`src/engine/import.hpp:1204`):**
   - In `refresh()`, call `drive.textExport(id)` when `!lens::hiddenChipTabs(actual).empty()` (or equivalent hidden-chip check) **or** `std::any_of(comments.begin(), comments.end(), [](const auto& c) { return !c.quote().empty(); })`.
