### Observed current and target state
- Current (verified by reading C `tests/diff/test_myers.hpp`):
  - The C `rngCreate` (lines 13–22) mirrors mulberry32.
  - Both random tests (lines 64–70 and 101–107) draw `a_len` and then `b_len` before drawing either sequence's characters.
- Draw-order difference (verified by reading N): the original draws the a-length, then a's characters, then the b-length, then b's characters. N uses `Array.from({length}, …)`, so each length is drawn before that sequence's own characters.
  - Result: every trial after the first draw diverges, so all trials except possibly the zero-length edge cases use different inputs.
- Assumption to resolve in 12-A: C uint32 wraparound matches JS `Math.imul`/`>>>0`, including `t ^= t + imul(...)`, where JS adds as a double and then applies ToInt32. Mathematically both are mod 2^32; prove it with the pinned-value check below.

  - A pinned input identity proves the generated inputs match the original's.

### Implementation recipe
- Steps:
  1. In both random TEST_CASEs, draw `a_len` and fill `a`, then draw `b_len` and fill `b`. Keep the `static_cast<int>(rng()*K)` truncation, which equals `Math.floor` for non-negative values.
  2. Factor the generator into one local inline `genPair(rng, alphabet, maxLen)` in the header. It's used by both tests and the control, so extraction is justified.
  3. Add a TEST_CASE "generated inputs match original draw order":
     - For seed 7 (`abc`, 14) and seed 11 (`xyz`, 10), regenerate every trial.
     - Compare against a pinned digest per seed, e.g. a concatenation of `a|b;` strings hashed with a simple in-header FNV-1a, plus the first few literal pairs. The values come from the spike artifact.
     - Also check the first three `rng()` raw outputs for seed 7 against the N-recorded values. This closes the PRNG-port assumption.
  4. Reordered-draw control: in the same test, generate with the old (both-lengths-first) order and `CHECK` that its digest differs from the pinned one.
  5. Nonminimal control: take a known pair, e.g. `abc` vs `abc`, and build a hunk list that deletes and reinserts all of it. `CHECK` that `hunksApply` reconstructs `b`, and `CHECK` that the edit count does not equal `a+b-2*lcsLength`. This proves the minimality assertion can fail.
- Behavior contract:
  - 500 trials for seed 7 and 300 for seed 11 are unchanged.
  - The identity must cover every trial, not a sample.
  - Expected output: all existing cases pass; the new case passes; the controls are asserted inside the test, not by mutating production code.
- Failure/lifecycle contract:
  - If the PRNG check mismatches, stop, keep the edits, and report the first differing index. Don't adjust constants to force a match.
  - Raw RED results are kept, never relabeled.
- Local decision boundary: the worker may choose the helper name, the digest function, and how many literal pairs to pin, at least three per seed.
- Escalate (to coord-v2, or the lead if unavailable): any `src/diff` change; touching any other test file; or any change to existing assertions, trial counts, seeds or alphabets.
