### Current State vs. Target State
- **W1 `doc: null`:** `src/lens/document.hpp:433` assigns `tab.id = "t.0"` when `tabs.empty()`, and `442-451` enforces `"An existing tab starts with its opening ::section{id=s1} line."` whenever `sourceEnvelope && !tab.id.empty() && !tab.isDelete`, without checking whether `file.frontmatter.doc` is empty/null. Node (`../gdocsmith-node/src/core/lens/document.ts:1104,1127-1135`) only requires `::section{id=…}` when `existing` is true (`Boolean(tab.id) && !tab.delete && metadata?.doc !== null`), while still parsing and stripping an opening `::section{id=…}` if present on a new document/tab.
- **W4 `baseValidate`:** `src/engine/import.hpp:1070-1077` re-exports `live` with empty comments `{}` and compares `base.tabs[i].markdown != current.tabs[i].markdown`. Because `src/lens/document.hpp:571-573` emits an extra `\n` before `::comment{...}` when `!file.comments.empty()` (and `!tab.openingSettings`) and `documentFileParse` (`src/lens/document.hpp:239-243`) preserves that trailing `\n` when `sourceVersion` is set, `base.tabs[i].markdown` has a trailing `\n` that `current.tabs[i].markdown` lacks, causing a false `staleBase` error on commented documents. Because `baseValidate` only compares `export.orig.md` (`base`) against `live` (`current`) and never compares the user's edited `export.md`, normalizing trailing `\n` in `baseValidate` cannot mask real body trailing-newline edits.
- **`11-A` `may_fail()` #1 (`tests/engine/test_import_structure.hpp:166`):** `src/engine/export.hpp:361-383` unconditionally emits `namedStyleSet=ns1` on the tab line whenever `tab.namedStyles["styles"]` is non-empty, even when `tab.namedStyles` matches Google's default `blankTab["namedStyles"]`. Node (`../gdocsmith-node/src/core/lens/namedStyles.ts:34-44`) diffs against `DEFAULT_NAMED_STYLES` and omits `namedStyleSet` when the diff is empty. Meanwhile `tests/engine/test_export.hpp` explicitly asserts `namedStyleSet=ns1` when `TITLE` differs from defaults.
- **`11-A` `may_fail()` #2 (`tests/engine/test_import_structure.hpp:192`):** `src/engine/import.hpp:766-768` throws `"The requested header/footer section does not exist."`, whereas Node (`../gdocsmith-node/src/core/engine/import.ts:1047`) throws `` `tab "${section.title}" has ${breaks + 1} section${breaks ? "s" : ""}, so there's no section ${segment.section}` ``.
- **`10-T3` `hiddenChipTabs` (`src/engine/import.hpp:1204`):** `refresh()` only calls `drive.textExport(id)` when a comment has a non-empty `quote()`. Node (`../gdocsmith-node/src/core/engine/export.ts:245-250`) calls `drive.textExport(model.docId)` when `hiddenChipTabs(model).length > 0` **or** a non-deleted comment has `quotedFileContent?.value`. `src/lens/hidden_chips.hpp` only defines `HIDDEN_CHIP` (`"\uE907"`) and `hiddenChipKindOf` (no `hiddenChipTabs`).

### Implementation Recipe
1. **W1 `doc: null` `::section{id=s1}` (`src/lens/document.hpp:442-472`):**
   - Compute `const bool existing = file.frontmatter.doc.has_value() && !file.frontmatter.doc->empty() && !tab.id.empty() && !tab.isDelete;`.
   - Under `if (sourceEnvelope && !tab.isDelete)`, look for `opening = lineDirectiveMatch(first, sectionNames)`.
   - If `!opening || opening->label || opening->attrs.get_value("id") != std::optional<std::string>{"s1"}`: throw `CoreError("unsupportedSyntax", "An existing tab starts with its opening ::section{id=s1} line.")` only if `existing` is true; otherwise leave `tab.markdown` as-is.
   - If `opening` is present and valid, validate flags/attributes, set `tab.openingSettings`, erase `first`, and check for duplicate `id=s1` as before.
   - Add unit tests in `tests/lens/test_document.hpp` verifying `doc: null` with `gdocsmith: "3.0.20"` and with `gdocsmith: 1` (and no `::section{id=s1}`) both parse without error.
2. **W4 `baseValidate` newline mismatch (`src/engine/import.hpp:1070-1077`):**
   - Add a local `trimTrailingNewlines` helper in `baseValidate` and normalize trailing `\n` on `base.tabs[i].markdown` and `current.tabs[i].markdown` before comparing.
   - Add a unit test in `tests/engine/test_import.hpp` verifying `baseValidate` succeeds on a commented document.
3. **`11-A` `may_fail()` #1 (`src/engine/export.hpp:361-383`, `tests/engine/test_import_structure.hpp:166`):**
   - In `src/engine/export.hpp:361-383`, compare `tab.namedStyles` against the default `namedStyles` from `emulator::blank_doc_template("", "")["tabs"][0]["documentTab"]["namedStyles"]` (per `namedStyleType` and exported declaration field, matching `../gdocsmith-node/src/core/lens/namedStyles.ts:34-44`).
   - Only add `docFile.frontmatter.namedStyleSets[name]` and `dft.readonlyAttributes.values.emplace_back("namedStyleSet", name)` when the diff is non-empty (preserving `namedStyleSet=ns1` for `tests/engine/test_export.hpp` while omitting it for default styles in `seedPaged`).
   - Remove `* doctest::may_fail()` from `tests/engine/test_import_structure.hpp:166`.
4. **`11-A` `may_fail()` #2 (`src/engine/import.hpp:766-768`, `tests/engine/test_import_structure.hpp:192`):**
   - Update `src/engine/import.hpp:766-768` to throw:
     `"tab \"" + section.title + "\" has " + std::to_string(breaks + 1) + " section" + (breaks ? "s" : "") + ", so there's no section " + std::to_string(*segment.section)`
   - Remove `* doctest::may_fail()` from `tests/engine/test_import_structure.hpp:192`.
5. **`10-T3` `hiddenChipTabs` (`src/engine/import.hpp:1204`):**
   - In `refresh()`, compute `hasHiddenChips` across `actual.tabs` (true if any top-level `block.is_paragraph()` has an inline with `item.is_text() && item.text.find("\uE907") != std::string::npos`), and call `drive.textExport(id)` when `hasHiddenChips || std::any_of(comments.begin(), comments.end(), [](const auto& c) { return !c.quote().empty(); })`.
