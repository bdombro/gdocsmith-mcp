     - Tiers, in order: `run`; then the paragraph's `paragraphStyle.namedStyleType` style in `tabs[0].documentTab.namedStyles.styles[]`; then the stored NORMAL_TEXT style; else `unresolved`.
     - A missing `namedStyleType` skips tier 2. The seed paragraph has `paragraphStyle: {}`.
     - Never default to 11.
   - `segments(doc)`: return `(startIndex, endIndex, textStyle)` per run (O4).
   - Pure predicates over JSON, used by both the tests and the controls:
     - `a1(post, pt)`
     - `a2(pre, post)` for the newline: explicit and effective style
     - `a3(pre, post)` for "Hello " and " world": map by text offset, because indices shift by the 8 inserted chars ("revised ")
3. **Test cases.** Write two separate cases and never merge them:
   - `TEST_CASE("import styles - 11pt stored font before readback omission")`
   - `TEST_CASE("import styles - 22pt stored font before readback omission")`

   Each case does the following:
   1. Create a `RemoteImportFixture` and call `seedFont`. Take `pre = backend.get_doc("synthetic_doc").json` (deep copy) and record O2/O3 for "Hello world\n".
   2. Take `auto file = fixture.file();` and replace "Hello world" with "Hello revised world" in the tab markdown. `CHECK` that the replacement happened.
   3. Install the batch-capture wrapper and the omission `getDocument` wrapper.
   4. Run `const auto result = fileImport(fixture.save(file), fixture.remote);`.
   5. `REQUIRE(fixture.batches >= 1)` and require that `post` is set.
   6. Keep the §1.1 assertions verbatim:
      - 11pt: `errors` absent, `verification == "match"`, `status == "applied"`
      - 22pt: `verification == "mismatch"`, `status == "failed"`, and the summary starts with "Every write landed, but the readback did not match the file"
   7. Record only, with `MESSAGE` and sanitized `slimr::write_json` dumps:
      - O1: every `updateTextStyle` in `sentRequests` (range, `fields`, `textStyle`)
      - O2: explicit fields for every index of the edited paragraph, including the newline
      - O4: segments
      - O5: copy `post`, set NORMAL_TEXT `textStyle.fontSize` to 13pt, re-run `perIndex`, and record which indices follow the 13pt value
   8. Assert:
      - **A1:** `CHECK(a1(post, pt))`. Every char of "Hello revised world" has effective size equal to `pt` and effective family Arial/400.
      - **A2:** `CHECK(a2(pre, post))`.
      - **A3:** `CHECK(a3(pre, post))`.
      - **A4 (22pt only):** call `fixture.remote.getDocument("synthetic_doc")` once (the transform is applied), then re-read storage. `CHECK` that the `perIndex` output equals the one taken from `post`.
4. **Negative controls.** Each one works on a **copy** of `post` and calls the same predicates. `CHECK` that the predicate fails with the fault applied and passes on an unmodified copy.
