  - `src/reconcile/paragraph.hpp` (`textStylesEmit` `:153-270`, `reconcileParagraph` `:524-552`), `src/model/edit.hpp:222-229`, and `src/emulator/document_emulator.hpp:571-576` already match Node's `reconcile/paragraph.ts`, `model/edit.ts`, and `emulator/emulate.ts` (`TEXT_STYLE_INHERIT_DROP_FIELDS` is `{"foregroundColor", "underline"}` in both). Because `put.hpp:422` supplied explicit font fields on `"revised "`, `textStylesEmit` (`:235`) emits `updateTextStyle [7, 15)` with explicit `fontSize` and `weightedFontFamily: Arial/400`, pinning `[1, 20)` in storage so only index `20` (`"\n"`) follows `NORMAL_TEXT` `13pt` in `O5`.
